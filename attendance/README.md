# Посещаемость кружка

Сайт учёта посещаемости для кружка МОФ «БІЛІМ-ИННОВАЦИЯ»: журнал занятий,
личный кабинет ученика, итоговый анализ пропусков за год, олимпиады и темы для изучения.

Данные хранятся в вашей Google-таблице. Сайт — статический (GitHub Pages),
сервером работает скрипт Google Apps Script.

## Что умеет

| Роль | Возможности |
|---|---|
| **Администратор** | всё: расписание, каникулы, ученики, сотрудники, удаление данных |
| **Помощник** | отмечать посещаемость, добавлять учеников, олимпиады и темы |
| **Ученик** | видит только свои посещения, пропуски, олимпиады и темы |

- Отметки: **Был**, **Опоздал**, **Уважительная**, **Пропуск**. Для длинных занятий
  можно указать, сколько часов ученик реально был (например, 2 из 4 в субботу).
- Расписание по умолчанию: Пн–Пт по 1 ч, Сб 4 ч, Вс выходной — меняется в настройках.
- Учеников можно добавлять в любой момент: у каждого есть дата зачисления,
  и занятия до неё в его статистику не попадают.
- Проценты считаются только по **проведённым** занятиям (где есть хоть одна отметка),
  поэтому в середине года цифры не занижаются.
- Выгрузка CSV (открывается в Excel): итоги посещаемости, олимпиады, темы.

## Установка (один раз, ~10 минут)

### 1. Таблица и скрипт

1. Создайте новую Google-таблицу (`sheets.new`). Назовите, например, «Кружок — посещаемость».
2. В меню: **Расширения → Apps Script**.
3. Удалите содержимое файла `Код.gs` и вставьте туда весь текст из [`Code.gs`](Code.gs).
4. Сохраните (значок дискеты).
5. Вверху выберите функцию **`setup`** и нажмите **Выполнить**.
   Google попросит разрешения — согласитесь (ваш аккаунт, ваша таблица).
6. Появится окно с кодом администратора — **запишите его**. Позже его можно
   только сбросить функцией `resetAdminPin()`.

### 2. Публикация скрипта

1. В редакторе Apps Script: **Развернуть → Новое развёртывание**.
2. Тип — **Веб-приложение**.
3. «Запуск от имени» — **Я**.
4. «У кого есть доступ» — **У всех** (иначе ученики не смогут открыть сайт).
5. Нажмите **Развернуть** и скопируйте ссылку, оканчивающуюся на **`/exec`**.

### 3. Сайт

1. Включите GitHub Pages для этого репозитория (Settings → Pages → ветка `main`).
2. Откройте `https://<ваш-логин>.github.io/<репозиторий>/attendance/`.
3. На первом экране вставьте ссылку `/exec` и нажмите «Сохранить и подключиться».
   Адрес сохранится в браузере. Чтобы прописать его для всех сразу, впишите его
   в `index.html` в строку `const DEFAULT_API_URL = '';`.
4. Войдите как администратор (имя «Администратор», код из шага 1.6).
5. Вкладка **Ученики** → добавьте список (можно сразу всех, по одному имени в строке).
   Система выдаст каждому 4-значный код — раздайте их ученикам.
6. В **Настройках** задайте название кружка, учебный год и расписание.

## Обновление кода

Если вы правите `Code.gs`, после сохранения нужно выпустить новую версию:
**Развернуть → Управление развёртываниями → карандаш → Версия: Новая → Развернуть**.
Ссылка `/exec` при этом не меняется.

## Частые вопросы

**Ученик забыл код.** Вкладка «Ученики» → «Новый код». Старый перестанет работать.

**Ученик ушёл из кружка.** Кнопка «В архив» — он пропадёт из журнала,
но его статистика и достижения сохранятся для годового отчёта.

**Занятие не состоялось.** Добавьте дату в «Каникулы и дни без занятий» —
этот день исчезнет из плана и никому не будет засчитан как пропуск.

**Можно ли работать без интернета?** Просмотр — да (последняя загруженная
страница кэшируется), отметки — нет, для них нужна связь с таблицей.
